## Phase 1

你的项目可以写成：

**RNNoise Neural Network Reimplementation | PyTorch / C / GRU**

* 阅读并分析 RNNoise C 推理实现，梳理 `Linear / Conv1D / GRU` 等基础算子的调用关系、Tensor shape 及 recurrent state 流转。
* 基于数学公式使用 PyTorch 手工重实现 RNNoise 核心网络模块，包括 Linear、时序 Conv1D 及 GRU，未直接调用 `nn.GRU` 完成核心计算。
* 建立 C / PyTorch 双实现数值验证流程，对输入、权重、hidden state 及各层输出进行逐层对齐，使用绝对误差等指标定位实现差异。
* 分析 recurrent state、权重布局、激活函数及浮点计算差异对跨语言实现一致性的影响。

注意：这段只有在你真正完成整个 Phase 1 后使用。
